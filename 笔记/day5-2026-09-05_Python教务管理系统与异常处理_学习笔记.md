# Python 教务管理系统与异常处理｜Day5 学习笔记

## 0. 本节课的主线

这一节不是孤立地练习某一个语法，而是把之前学过的容器、循环、判断和推导式组合起来，完成一个可以持续操作的教务管理系统。

```text
设计学生成绩的数据结构
        ↓
用 while True 让系统持续运行
        ↓
用 match...case 分配菜单功能
        ↓
完成学生信息的增、删、改、查
        ↓
遍历全班数据并统计成绩
        ↓
初步接触 try...except 异常处理
```

本节对应的实际练习文件是：

- `day5/教务系统练习.py`
- `day5/报错练习草稿.py`

## 1. 先设计系统的数据结构

系统使用一个字典保存全班学生：

```python
edu_system = {}
```

添加学生后，数据会变成下面的结构：

```python
edu_system = {
    "张三": {
        "语文": 90,
        "数学": 85,
        "英语": 88,
    },
    "李四": {
        "语文": 80,
        "数学": 92,
        "英语": 86,
    },
}
```

这是一个嵌套字典：

```text
外层字典
├── 键：学生姓名
└── 值：该学生的成绩字典
    ├── 语文 → 分数
    ├── 数学 → 分数
    └── 英语 → 分数
```

取值时要从外向内逐层进入：

```python
student_scores = edu_system["张三"]
chinese_score = edu_system["张三"]["语文"]
```

执行结果：

```text
student_scores → {"语文": 90, "数学": 85, "英语": 88}
chinese_score  → 90
```

字典中的 `[]` 是按“键”取值，不是列表中的位置索引。

## 2. 用 while True 让系统持续运行

系统主体是：

```python
while True:
    choice = input("请输入要执行的操作(1-7): ")
```

执行顺序是：

```text
进入 while True
    ↓
等待用户输入 choice
    ↓
执行对应功能
    ↓
本轮结束
    ↓
回到循环开头，再次等待输入
```

`while True` 的条件永远成立，因此系统会一直运行，直到执行 `break`。

```python
case "7":
    print("退出系统")
    break
```

这里的 `break` 会结束整个 `while` 循环，也就是退出系统。

## 3. 用 match...case 分配菜单功能

`input()` 返回的是字符串，因此选项要写成 `"1"`、`"2"`，而不是整数 `1`、`2`。

```python
choice = input("请输入要执行的操作(1-7): ")

match choice:
    case "1":
        # 添加学生
    case "2":
        # 修改学生
    case "7":
        # 退出系统
    case _:
        print("输入错误，请重新输入")
```

可以把它理解为：

```text
choice 是 "1" → 执行 case "1"
choice 是 "2" → 执行 case "2"
choice 是 "7" → 执行 case "7"
其他任何内容 → 执行 case _
```

`case _` 是兜底分支，负责处理没有被前面选项匹配的输入。

## 4. 完成学生信息的增、删、改、查

### 4.1 添加学生

先接收输入，并用 `int()` 把成绩文本转换为整数：

```python
name = input("请输入学生姓名:")
chinese = int(input("请输入语文成绩:"))
math = int(input("请输入数学成绩:"))
english = int(input("请输入英语成绩:"))
```

然后判断学生是否已经存在：

```python
if name in edu_system:
    print(f"{name}已存在，请重新输入")
    continue
else:
    edu_system[name] = {
        "语文": chinese,
        "数学": math,
        "英语": english,
    }
```

`name in edu_system` 检查的是外层字典中是否存在这个键。

如果学生已存在，`continue` 会结束当前这一轮循环，直接回到 `while True` 的开头。它与 `break` 的区别是：

```text
continue → 只结束本轮，系统继续运行
break    → 结束整个循环，退出系统
```

### 4.2 修改学生

```python
if name in edu_system:
    edu_system[name] = {
        "语文": chinese,
        "数学": math,
        "英语": english,
    }
```

这里仍然是字典赋值：

- 姓名不存在时，这是新增键值对。
- 姓名已经存在时，新成绩会替换原来的值。

修改功能先检查姓名是否存在，因此只有已有学生会被更新。

### 4.3 删除学生

```python
if name in edu_system:
    del edu_system[name]
```

`del edu_system[name]` 会删除姓名和它对应的整份成绩字典。

删除前先判断姓名是否存在，可以避免访问不存在的键而产生 `KeyError`。

### 4.4 查询单个学生

```python
print(
    f"{name}的语文成绩是{edu_system[name]['语文']},"
    f"数学成绩是{edu_system[name]['数学']},"
    f"英语成绩是{edu_system[name]['英语']}"
)
```

以语文成绩为例，取值过程是：

```text
edu_system
    ↓ 使用 name 作为键
edu_system[name]
    ↓ 使用 "语文" 作为键
edu_system[name]["语文"]
    ↓
最终分数
```

## 5. 用 items() 列出所有学生

```python
for name, scores in edu_system.items():
    print(name, scores)
```

假设字典中有两名学生，循环过程是：

```text
第 1 轮：name = "张三"
          scores = {"语文": 90, "数学": 85, "英语": 88}

第 2 轮：name = "李四"
          scores = {"语文": 80, "数学": 92, "英语": 86}
```

`.items()` 每轮提供一个 `(键, 值)` 元组；`name, scores` 再把这个元组解包到两个变量中。

这也是 Day4 解包知识在真实项目中的应用。

## 6. 统计前先处理空字典

如果系统中没有学生，直接执行 `max()` 或 `min()` 会报错。因此先判断：

```python
if not edu_system:
    print("目前没有学生信息，请先添加学生")
    continue
```

空字典 `{}` 在条件判断中相当于 `False`：

```text
edu_system 是空字典
        ↓
bool(edu_system) 是 False
        ↓
not edu_system 是 True
        ↓
进入 if 分支
```

打印提示后执行 `continue`，回到菜单，不再执行下面的统计代码。

## 7. 用字典推导式提取单科成绩

原始数据同时包含三科成绩。为了统计语文成绩，先生成一个只保存姓名和语文分数的新字典：

```python
chinese_scores = {
    name: scores["语文"]
    for name, scores in edu_system.items()
}
```

假设原数据是：

```python
edu_system = {
    "张三": {"语文": 90, "数学": 85, "英语": 88},
    "李四": {"语文": 80, "数学": 92, "英语": 86},
}
```

推导式每轮的变量和结果是：

```text
第 1 轮：name = "张三"，scores["语文"] = 90
第 2 轮：name = "李四"，scores["语文"] = 80
```

最终得到：

```python
chinese_scores = {"张三": 90, "李四": 80}
```

字典推导式的一般形式是：

```python
{新键: 新值 for 临时变量 in 可遍历对象}
```

它的普通循环写法是：

```python
chinese_scores = {}

for name, scores in edu_system.items():
    chinese_scores[name] = scores["语文"]
```

## 8. 计算最高分、最低分和平均分

### 8.1 values() 只取得分数

```python
chinese_scores.values()
```

对于 `{"张三": 90, "李四": 80}`，`.values()` 提供的是 `90` 和 `80`，因此可以交给统计函数。

### 8.2 三项统计

```python
highest = max(chinese_scores.values())
lowest = min(chinese_scores.values())
average = sum(chinese_scores.values()) / len(chinese_scores)
```

输入、处理、输出关系是：

```text
输入：90、80
处理：max / min / sum ÷ 人数
输出：最高分 90、最低分 80、平均分 85.0
```

输出平均分时：

```python
print(f"语文平均分是:{average:.2f}")
```

`:.2f` 表示把浮点数格式化为保留两位小数，例如 `85.00`。

### 8.3 找到最高分和最低分学生

```python
for name, score in chinese_scores.items():
    if score == max(chinese_scores.values()):
        print(f"语文最高分学生：{name}")

    if score == min(chinese_scores.values()):
        print(f"语文最低分学生：{name}")
```

循环逐个比较每名学生的成绩。如果多人并列最高分或最低分，满足条件的姓名都会被打印出来。

数学和英语统计采用了相同思路：先提取单科字典，再计算最高分、最低分、平均分及对应学生。

## 9. 初步接触 try...except 异常处理

练习草稿中的结构是：

```python
try:
    print(1 / 0)
except:
    print("变量my_name未定义")
```

`try` 的意思是“尝试执行这段代码”；发生异常后，程序会跳到 `except`。

但这段代码中，实际错误和提示内容不一致：

```text
实际执行：1 / 0
实际异常：ZeroDivisionError
当前提示：变量 my_name 未定义
```

准确的写法应是：

```python
try:
    print(1 / 0)
except ZeroDivisionError:
    print("除数不能为零")
```

如果练习变量未定义，则是另一种异常：

```python
try:
    print(my_name)
except NameError:
    print("变量 my_name 未定义")
```

本阶段需要先认识三种常见异常：

```text
NameError          使用了不存在的变量
ZeroDivisionError  除数为零
ValueError         值的格式不符合转换要求
```

例如，在教务系统中输入 `九十`：

```python
score = int("九十")
```

这会触发 `ValueError`，因为 `int()` 不能把这段文字转换为整数。

裸写 `except:` 会捕获几乎所有异常，但也会把不同问题混在一起，使提示与真实原因不一致。学习阶段应优先写出明确的异常类型。

## 10. 本节容易混淆的点

- `input()` 的结果是字符串，因此 `match choice` 中应写 `case "1"`，不能写 `case 1`。
- `break` 结束整个循环；`continue` 只跳过本轮剩余代码，然后开始下一轮。
- `name in edu_system` 检查的是外层字典中是否存在这个姓名键。
- `edu_system[name]["语文"]` 是连续访问两层字典，不是二维列表索引。
- `.items()` 提供键和值，`.values()` 只提供值。
- `{name: score for ...}` 是字典推导式；外层 `{键: 值}` 决定结果是字典。
- `if not edu_system` 用于判断字典是否为空，避免对空数据使用 `max()` 和 `min()`。
- `:.2f` 只负责输出格式，不会修改原变量保存的数值。
- `except:` 能接住异常，不代表异常提示就是正确的；提示必须与实际异常类型对应。
- 当前代码会直接对成绩执行 `int(input(...))`，输入非整数时仍会报错，这是下一阶段需要补充的输入校验。
