# Python 容器与成绩数据处理｜Day4 学习笔记

## 0. 本节课的主线

这一节从“一个列表里怎么增删元素”，延伸到“怎样处理多名学生的成绩记录”。主线是：

```text
列表、元组、集合的区别
        ↓
用索引从有顺序的数据中取值
        ↓
列表按位置或按值增删元素
        ↓
用循环 / 列表推导式计算每条记录
        ↓
用解包、zip()、enumerate()整理并输出结果
```

本笔记只整理 Day3「自动化考勤」之后学习的内容，不重复 Day1 的 pandas/Excel 与 Day2、Day3 内容。

## 1. 三种基础容器：list、tuple、set

### 1.1 列表 list

列表有固定顺序，可以修改。

```python
names = ["小明", "小红", "小刚"]
```

- 可以按索引取元素：`names[0]` 是 `"小明"`。
- 可以添加、删除或修改元素。

### 1.2 元组 tuple

元组也有固定顺序，也能按索引取元素，但创建后不能修改。

```python
goods = ("鼠标", 188, 2)

print(goods[0])  # 鼠标
print(goods[1])  # 188
```

商品名称、单价、数量这类结构固定的数据，可以用元组表示。

### 1.3 集合 set

集合的特点是元素不重复、没有可依赖的固定位置。

```python
skills = {"Python", "Excel", "Python"}
print(skills)  # Python 只会保留一份
```

`set` 的“无序”不是说它每次都随机排列，而是说不能依赖“第 0 个”或“最后一个”的位置，因此不能写 `skills[0]`。

```python
skills.add("SQL")   # 加入元素，不存在“加到最后”
one_skill = skills.pop()  # 删除并返回一个任意元素
```

## 2. 索引（下标）：从数据中取位置

在当前 Python 学习中，“索引”和“下标”可以当作同义词：都是元素的位置编号。

```python
names = ["小明", "小红", "小刚"]
#          0       1       2

print(names[0])   # 小明
print(names[1])   # 小红
print(names[-1])  # 小刚，最后一个
```

Python 从 `0` 开始计数：`names[0]` 的含义是“从开头移动 0 格后取得的元素”。

同一个 `[]` 符号要看上下文：

```python
new_list = []      # 创建一个空列表
first = names[0]   # 从 names 按索引取元素
```

列表、元组、字符串能按索引取元素；集合因为没有固定位置，不能用整数索引取元素。

## 3. 列表的添加与删除：按位置还是按值

```python
names = ["小明", "小红", "小刚"]
```

### 3.1 添加元素

```python
names.append("小李")       # 加到末尾
names.insert(1, "小王")     # 在下标 1 的位置前插入

print(names)
# ['小明', '小王', '小红', '小刚', '小李']
```

- `append(value)`：默认在末尾添加。
- `insert(index, value)`：在指定索引位置前插入。原来该位置及后面的元素会向右移动。

### 3.2 按位置删除：pop()

```python
names = ["小明", "小红", "小刚"]

last_name = names.pop()   # 删除最后一个，并得到 "小刚"
removed = names.pop(1)    # 删除下标 1，并得到 "小红"
```

`pop()` 的参数只能是位置（索引），不能写成 `names.pop("小红")`。不传参数时，它默认删除最后一个元素。

### 3.3 按值删除：remove()

```python
names = ["小明", "小红", "小刚", "小红"]
names.remove("小红")

print(names)
# ['小明', '小刚', '小红']
```

`remove(value)` 删除第一个匹配的元素值；它不是按索引删除。

一句话区分：

```text
pop(1)         按位置删，并返回被删掉的元素
remove("小红")  按值删，只删第一个匹配项
```

## 4. 列表推导式：批量产生一个新列表

例如，每个商品记录都是“商品名、单价、数量”：

```python
args = [
    ("鼠标", 188, 2),
    ("键盘", 388, 1),
]

item_totals = [goods[1] * goods[2] for goods in args]
print(item_totals)        # [376, 388]
print(sum(item_totals))   # 764
```

列表推导式的一般形式是：

```python
[结果 for 临时变量 in 数据集合]
```

上面的代码等价于普通循环：

```python
item_totals = []

for goods in args:
    item_total = goods[1] * goods[2]
    item_totals.append(item_total)
```

`item_totals` 保存每件商品的小计；`sum(item_totals)` 才是订单总价。

## 5. 嵌套学生成绩：先确定一行数据的结构

学生表可以表示为“外层列表装多名学生，内层记录装一名学生的信息”：

```python
students = [
    ["S001", "小明", 90, 88, 92],
    ["S002", "小红", 95, 86, 91],
]
```

其中一条 `student` 记录的结构是：

```text
student[0]  学号
student[1]  姓名
student[2:] 三门成绩
```

因此，总分只能对成绩字段求和：

```python
for student in students:
    total = sum(student[2:])
    print(student[1], total)
```

不能直接写 `sum(student)`，因为一行里同时包含学号、姓名字符串和数字成绩，字符串与数字不能相加。

如果成绩字段不连续，例如英语在下标 `5`，可以明确取需要的字段：

```python
total = sum(student[index] for index in (2, 3, 5))
```

这里 `sum(...)` 内部是生成器表达式：它逐个提供成绩给 `sum()`，不必先额外创建一个成绩列表。

## 6. 用推导式、解包和组包计算总分

### 6.1 一次算出所有学生总分

```python
every_total_score = [sum(student[2:]) for student in students]
```

外层 `[]` 决定结果是列表；它会得到每位学生的总分，例如 `[270, 272]`。

### 6.2 扩展解包：把固定前两项和可变成绩分开

```python
for student in students:
    student_id, name, *scores = student
    total = sum(scores)
    print(name, total)
```

执行 `student_id, name, *scores = student` 后：

```text
student_id  → "S001"
name        → "小明"
scores      → [90, 88, 92]
```

`*scores` 会把剩余元素组装为一个列表，适合“成绩科目数量可能变化”的记录。

组装新结果时，可以写：

```python
result = (student_id, name, sum(scores))
```

这叫组包：把多个值放进一个元组，形成“学号、姓名、总分”这一条新记录。

## 7. 学生与总分怎样一一对应

总分列表与学生列表不会自动关联，需要明确配对。

### 7.1 zip()：把两个等长序列按相同位置配对

```python
for student, total_score in zip(students, every_total_score):
    print(f"{student[1]} 的总分是 {total_score}")
```

每一轮分别取：

```text
第 1 轮：students[0] 与 every_total_score[0]
第 2 轮：students[1] 与 every_total_score[1]
```

### 7.2 enumerate()：同时拿到索引和当前元素

```python
for index, student in enumerate(students):
    print(f"{student[1]} 的总分是 {every_total_score[index]}")
```

`enumerate()` 是内置函数，不是列表方法。它每轮产生一对数据：`(索引, 当前学生)`。

## 8. 本节容易混淆的点

- `set` 无固定位置，不等于“添加、删除元素是随机的”。只有不指定对象的 `set.pop()`，返回哪个元素不可依赖。
- `append()` 和不带参数的 `list.pop()` 默认操作列表末尾；`insert()`、`pop(index)`、`remove(value)` 各自有不同规则。
- `goods[1]` 是按索引取数据，不是创建列表。
- `sum(a, b, c)` 不对；应使用 `sum((a, b, c))`，或 `sum(scores)`。
- `list1[[2], [3], [4]]` 不是 Python 的多索引写法。连续字段用切片，非连续字段用循环逐个取。
- `for row in (2, 3, 4)` 遍历的是数字 2、3、4，不是学生记录；学生循环必须写在外层。
- `for i, z in every_total_score, students[1]` 不是两个序列的配对遍历，应使用 `zip()`。
